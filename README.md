Prototipo de una página de presentación de producto desarrollado para el curso de Web Móvil.

## Tecnologías

HTML, CSS, JavaScript y GSAP.

## Ejecución

Abrir `index.html` en un navegador o usar Live Server. No requiere instalar paquetes.

## Archivos principales

- `index.html`: contenido y estructura de la página.
- `css/styles.css`: estilos generales, hero y visor 3D.
- `css/caracteristicas.css` y `css/modelos.css`: estilos de esas secciones.
- `js/script.js`: entrada del hero y controles del visor.
- Los otros archivos de `js/` controlan las animaciones de cada sección.
- `assets/seda-reflejos.webp`: luces y sombras de la tela. El SVG las recorta con la forma animada.
